## Project 4 — Personal Profile Page

A personal profile page built as part of my HTML & CSS learning journey.

**Features:**
- Responsive layout (mobile + desktop)
- Light blue background with cherry blossom pink accent
- Animated section headings on hover
- Pill-style hobby tags
- Clickable LinkedIn & GitHub buttons
- Smooth scroll behavior

**Note on AI Usage:**
> HTML structure written independently by Rishav Raj.
> CSS (colors, typography, animations, hover effects, layout) designed with assistance from **Claude AI by Anthropic** (claude.ai).
> This is a learning project — AI was used as a design tool, not to write the HTML logic.

---

## Technologies Used

- HTML5
- CSS3 (Flexbox, CSS Variables, Animations, Media Queries)
- Google Fonts (Playfair Display + DM Sans)

---

## What I Learned

- Semantic HTML tags (`header`, `main`, `section`, `footer`)
- CSS variables for consistent theming
- Hover animations with `::after` pseudo-elements
- Responsive design using `@media` queries
- Proper use of `<a href="mailto:">` and `target="_blank"`
